# numb-form

> Maschinelle Übersetzung (Argos Translate) des [englischen Originals](../../README.md). Maßgeblich ist die englische Fassung.

Füllt Abschnitt A des Formulars *Appendix A - Risk Assesment* für jedes Unternehmen in der Übersichtstabelle aus, die noch keinen Ordner hat.

Sie bestätigen jedes Dokument, es sei denn, Sie konfigurieren es unbeaufsichtigt. Die Tabellenkalkulation wird nie geändert.

Starten Sie es im Ordner über dem Arbeitsordner:

```
cd /path/to/folder-above && numb-form
```

Unter Windows, in Command Prompt:

```
cd /d "S:\path\to\folder-above" && numb-form
```

In Windows PowerShell:

```
Set-Location 'S:\path\to\folder-above'; if ($?) { numb-form }
```
