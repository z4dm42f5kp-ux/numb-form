# taube Form

> Maschinelle Übersetzung (Argos Translate) des [englischen Originals](../../README.md). Maßgeblich ist die englische Fassung.

Füllt Abschnitt A des Formulars *Anhang A - Risikobeurteilung* für jeden
Unternehmen in der `3. Übersichten`-Tabelle, die noch keinen Ordner hat.

Es funktioniert mit einer Kopie in Ihrem Downloads-Ordner.
Sie bestätigen jedes Dokument.
`numb-commit` kopiert die überprüften Ordner zurück.

```
cd "C:\path\to\folder-above-the-working-folder" && numb-form && numb-commit
```

`numb-commit` fragt, bevor es etwas schreibt.
Überprüfen Sie die Kopie in Downloads, bevor Sie antworten.
